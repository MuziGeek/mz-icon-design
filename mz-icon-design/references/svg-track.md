# SVG Track: mz-line-v1

Use this track for functional 16-32px UI icons. Output one original SVG per concept.

```svg
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" xmlns="http://www.w3.org/2000/svg">
  <!-- drawing primitives -->
</svg>
```

- Keep drawings inside the 20x20 safe area from x/y 2 to 22.
- Prefer 1-4 drawing primitives; six is the hard review limit.
- Use round terminals, rounded joins, simple geometry, and balanced negative space.
- Do not use gradients, filters, masks, patterns, images, text, scripts, animation, external references, event attributes, or opaque fills.
- Render at 16px, 24px, and 32px on light and dark backgrounds. Rework crowding, uneven visual weight, or semantic ambiguity before review.
