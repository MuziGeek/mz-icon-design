# MZ Core

Apply these invariants before every Preset and Asset Profile.

- Express one primary concept per asset.
- Prefer restraint, legible hierarchy, and purposeful negative space.
- Allow controlled human imperfection; never substitute random roughness for craft.
- Keep dimensions, names, versions, and validation evidence traceable.
- Use only original geometry, prompts, composition, and assets. Translate external references into general intent rather than copying visual signatures.
- Stop at `READY_FOR_REVIEW`; only the user can accept a visual asset.

Core rules are non-overridable. Presets define appearance; modifiers may only alter their declared rule paths.
